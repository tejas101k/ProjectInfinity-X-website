ROM Issue Tracker

Help us improve Project Infinity X. Report reproducible bugs originating from the original, unmodified ROM source codebase.

Submit Bug Report View Open Issues

Important — Read Before Submitting

This issue tracker is ONLY for bugs related to the original, unmodified Project Infinity X ROM source. Device-specific issues, hardware bring-up bugs, kernel panics, or modified system environments will be closed immediately without exception.

Accepted ROM Source Issues
  • SystemUI or interface bugs originating from ROM source
  • Core ROM framework & system functionality issues
  • Launcher bugs caused by ROM source changes
  • Bugs in built-in Infinity X system applications
  • Reproducible issues affecting the original source code
Do NOT Report Here
  • Device-specific tree, kernel, or vendor blob issues
  • Issues while Root (Magisk/KernelSU) or modules are active
  • Third-party app compatibility (banking, payment apps, etc.)
  • Device update requests or adding new supported devices
  • General ROM queries, feature requests, or user support
Stock State Requirement

All bug reports must be verified on an unmodified stock state. Ensure you have removed root modifications, Xposed/LSPosed modules, and custom kernel tweaks before testing. Reports found to be caused by user-applied modifications will be closed.

Reproduction Policy

The source maintainer will attempt to reproduce the issue using your provided steps. Steps must be clear, accurate, complete, and repeatable. Reports without proper reproduction steps or required logs will be closed.
